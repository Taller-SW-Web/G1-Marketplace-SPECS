## Implementación

- Dockerfile por repositorio de aplicación, Node 22.18.0, etapas build/runtime y usuario node. .dockerignore excluye secretos/env, Git, dependencias/builds del host, reportes y el next-env.d.ts local.
- Backend añade compose.h3.yaml: PostgreSQL 16 con volumen independiente, Backend Nest y Frontend Next de la carpeta hermana. Publica sólo 127.0.0.1:3000 y 127.0.0.1:10000; PostgreSQL permanece en la red interna.
- depends_on/healthchecks ordenan PostgreSQL → Backend → Frontend. Backend aplica las migraciones Prisma existentes a la BD del contenedor, sin montar el inicializador SQL del Compose antiguo ni operar sobre BD externas.
- El entorno de catálogo es MOCK explícito, Backend NODE_ENV=development y Frontend Next compilado. No activa G6 REAL, no sustituye el contrato externo ni implementa semanas posteriores a la 8.
- Next consulta http://backend:10000. marketplaceApiUrl, usado por los proxies de catálogo y carrito, exige configuración explícita MARKETPLACE_INTERNAL_HTTP_HOST=backend para ese HTTP interno. Conserva HTTPS/loopback y rechaza otros hosts HTTP, credenciales, rutas, query y fragmentos. Las entradas del navegador no deciden el origen del BFF.
- Nuevas pruebas de URL y workflow FE para construir ambos Dockerfiles, levantar el Compose, comprobar readiness real de la BD, home/búsqueda por Next→BFF y carrito anónimo, y detener siempre el proyecto.

Guías: [Backend](https://github.com/Taller-SW-Web/G1-Marketplace-Backend/blob/feat/s1-f006-f007-catalogo/docs/DOCKER-H3.md), [Frontend](https://github.com/Taller-SW-Web/G1-Marketplace-Frontend/blob/feat/s1-f006-f007-catalogo/docs/DOCKER-H3.md). Deben estar en carpetas hermanas. El docker-compose.yml previo sólo levanta PostgreSQL/Adminer y se conserva; el flujo nuevo utiliza explícitamente compose.h3.yaml y otro proyecto/volumen.

## Ejecución por Giuliano

Instalar y abrir Docker Desktop con contenedores Linux. Desde G1-Marketplace-Backend:

```powershell
docker compose -f compose.h3.yaml up --build --detach --wait --wait-timeout 180
docker compose -f compose.h3.yaml ps
```

Abrir http://localhost:3000/catalogo. Para detener conservando la BD: docker compose -f compose.h3.yaml down. No usar down -v como parada habitual.

Las pruebas de CI se ejecutan sólo sobre el proyecto propio con fixtures. No son una integración G6 ni una aceptación humana.
