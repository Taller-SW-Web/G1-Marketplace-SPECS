# Spec funcional — F-037 Visualizar favoritos

| ID | Estado |
|---|---|
| `F-037` | Aprobada; enriquecimiento Catálogo condicionado por `I-01`. |

Lista favoritos propios en orden más reciente, enriquecidos con datos vigentes de catálogo. Producto retirado se muestra como no disponible o se omite según respuesta, sin borrar automáticamente intención del usuario.

- [ ] **CA-F037-01:** Sólo se ven favoritos del JWT.
- [ ] **CA-F037-02:** Lista vacía es válida.
