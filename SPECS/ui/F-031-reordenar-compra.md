# Spec UI — F-031 Reordenar compra

En detalle de pedido aparece “Agregar productos al carrito”. Tras confirmar muestra productos agregados, cantidades ajustadas y no disponibles; acciones Ver carrito/Cerrar. No se llama “Comprar de nuevo” porque aún no hay checkout.

CTA ocupado evita doble envío; resultados parciales usan texto/iconos y `aria-live`.

- [ ] **UI-F031-01:** Usuario entiende que reordenar no confirma compra.
