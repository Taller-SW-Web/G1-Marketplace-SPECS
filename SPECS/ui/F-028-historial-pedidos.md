# Spec UI — F-028 Historial de pedidos

Ruta `/mis-pedidos`; tarjetas o tabla responsive con código, fecha, total, estado y enlace al detalle. Estados: skeleton, lista, vacío y error recuperable. Filtros se añaden en F-029.

Badges incluyen texto/icono/color; en móvil cada pedido es tarjeta. El estado vacío enlaza a catálogo.

- [ ] **UI-F028-01:** Cada pedido tiene un enlace accesible a su detalle.
