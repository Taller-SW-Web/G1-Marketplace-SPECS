# Specs depreciadas

Esta carpeta conserva las ocho especificaciones técnicas previas (`SPEC-01` a `SPEC-08`) únicamente como evidencia histórica y fuente de consulta.

No son la fuente de verdad vigente: para trabajo SDD nuevo se usan las specs individuales de `funcional/`, `ui/` y `contrato-api/`, junto con el modelo lógico de datos y los contratos homologados.
